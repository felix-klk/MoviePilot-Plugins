# NEO字幕大师修复方案

更新于 2026-11-22。NEO字幕大师由 `felix-klk` 维护，插件 ID 为 `NeoSubtitleMaster`。V2 的首个适配版本为 0.1.0，实机验收待完成。现阶段优先验收 V3 1.0.0 的核心功能。本机 MoviePilot 3.2.9 已核对安装文件，端到端验收待完成。

## V2 适配范围

V2 版以 NEO V3 为功能基线，覆盖字幕搜索与上传、智能调轴、Emby 多服务器和媒体库选择、目录监控与存量扫描、按视频路径去重、持久化队列和双语补搜。整理历史、媒体识别、事件注册、插件管理和 Emby 服务使用 MoviePilot 2.13.5 的 V2 接口。整理历史中的 TMDB 或豆瓣 ID 与目录 NFO、入库事件归一后可用于同组媒体定位。[MoviePilot V2.13.5 宿主源码](https://github.com/jxxghp/MoviePilot/tree/v2.13.5/app)

V2 和 V3 使用相同的插件 ID。V2 从 0.1.0 起算，V3 从 1.0.0 起算，因为发布工作流按插件 ID 和版本号生成唯一标签。旧海拉鲁字幕大师仍可作为独立插件安装。NEO 首次安装使用自己的配置、索引和队列，切换时需在 NEO 重新保存所需设置。

本地验证通过了字幕专项回归、5 套前端检查及版本一致性检查。V2 构建产物包含设置页、桌面和移动入口，模拟打包校验通过。测试覆盖整理历史与目录 NFO 归组、同路径去重、队列重启续跑和 Emby 掉线恢复。

## 实机验收步骤

1. **安装与配置。** 在 V2 和 V3 分别核对插件 ID、版本、侧栏及插件设置。各版选择两台 Emby 并保存，重开后核对服务器和媒体库回显。
2. **本地目录与队列。** 在 Windows 原生 MoviePilot 可用 `F:\1111\流人 第六季 (2026)` 复测。容器内改用实际挂载路径。先用空目录确认无任务，再导入可读的无字幕视频，执行「检查已有视频」。重复点击并重启宿主，确认同一路径只有一条有效任务，未完成任务会恢复。移除并恢复测试挂载，确认目录恢复后会重新检查。
3. **字幕冲突与语言。** 准备两个同集不同片源的视频。给其中一个准备合格的 `HDR10+.中英双语.zh-CN.ass`，另一个保留为缺字幕。已有合格字幕的视频应跳过，另一个仍可入队。对仍冲突的目标检查写入预览提示，并核对原字幕文件内容未被覆盖。
4. **Emby 与双语补搜。** 暂停一台测试 Emby。另一台应仍可读取；依赖离线服务器的任务应保留等待状态。恢复连接后核对重查和补搜结果，确认仅通知所选范围的 Emby 刷新字幕。

验收记录应包含 MoviePilot 与插件版本、平台、测试日期、每项结果及必要日志。字幕源密钥、代理凭据和 Emby Token 应从记录中移除。
