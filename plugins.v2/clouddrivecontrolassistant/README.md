# CloudDrive控制助手 · MoviePilot V2

在 MoviePilot V2（2.10.0 至 3.0.0，不含）中添加 [felix-klk/MoviePilot-Plugins](https://github.com/felix-klk/MoviePilot-Plugins)，在商城搜索 **CloudDrive控制助手**，作者 `felix-klk`。插件 ID 为 `CloudDriveControlAssistant`。安装包见 [CloudDriveControlAssistant_v2.0.0](https://github.com/felix-klk/MoviePilot-Plugins/releases/tag/CloudDriveControlAssistant_v2.0.0)。

进入插件设置，填写 CloudDrive2 地址和 API 令牌，按需开启「外网播放保护」和「异常通知」。新插件单独保存设置。从 `Cd2Assistant` 切换时，先让旧插件恢复它暂停的任务或设置的限速。上传与复制/移动控制、限速权限和实机验证见 [使用说明](https://github.com/felix-klk/MoviePilot-Plugins/blob/main/plugins.v3/clouddrivecontrolassistant/README.md)。
