# CloudDrive2助手 NEO(自用版) · MoviePilot V2

适用于 MoviePilot 2.10.0 及以上的 V2 版本。在插件市场添加 `https://github.com/felix-klk/MoviePilot-Plugins`，搜索 **CloudDrive2助手 NEO(自用版)** 并安装 **2.3.1**。已经安装 `Cd2Assistant` 时可选择本仓库进行更新，插件 ID 相同，可沿用本机已有配置。手动选历史版本时，V2 选择 `Cd2Assistant_v2.3.1`，V3 选择对应的 3.x 版本。

1. 打开插件设置，启用插件并添加 CloudDrive2 连接。服务器地址与 API 令牌分开填写，权限见下文。
2. 按需开启「外网播放传输保护（忽略内网）」。默认每 10 秒检查 MP 已配置的媒体服务器，所有外网播放停止或暂停后等待 45 秒，仅恢复由插件暂停的任务。
3. 开启「通过 MoviePilot 通知」，在 MP 的 Telegram 等渠道中允许所选消息类型（默认「手动处理」）。勾选「高级设置中的「立即检查一次」」并保存可触发检测。周期检测默认每 10 分钟运行。

插件使用 CloudDrive2 gRPC 分页检查上传错误，并检查服务是否就绪、网盘是否锁定及目录能否读取。空目录正常，持续相同的故障只通知一次。目录探测只读，定时检测只报告检查时仍可查到的异常。

## API 令牌

在 CloudDrive2 网页进入「API 令牌 → 创建令牌」，指定有效期和需要的权限。在插件首页分别填写服务器地址和 API 令牌。首页编辑首个连接，已保存的令牌留空即可沿用。其他已存在的连接继续运行。地址须从 MoviePilot 所在机器或容器可达。CloudDrive2 的默认 gRPC 端口是 19798；若通过支持 gRPC 的 TLS 入口访问，填 `https://你的域名` 或带端口的 HTTPS 地址。

- **监控**：列目录（`allow_list`）、获取云存储信息（`allow_get_cloud_apis`）、查看传输任务（`allow_get_transfer_tasks`）。检查整台服务器时，将令牌的根目录设为 `/`。
- **外网播放暂停/恢复**：再启用修改传输任务（`allow_modify_transfer_tasks`）。
- **可选功能**：仪表板或 HomePage 再启用运行信息和空间信息（`allow_view_runtime_info`、`allow_get_space_info`）。离线下载和重启分别需要 `allow_add_offline_download` 和 `allow_service_control`。

令牌直接用于 Bearer 认证。到期或被撤销后，创建新令牌替换原值即可。更换令牌时保留原实例名和 gRPC 地址，以便接续已暂停的任务。旧的 `名称#地址#用户名#密码` 格式仍可用。从旧格式切换前，若插件暂停了上传，请先关闭「外网播放时暂停上传」，保持插件启用，确认任务恢复后再换令牌。

[CloudDrive2 官方 API 开发者指南](https://www.clouddrive2.com/api/CloudDrive2_gRPC_API_Guide.html)

## 外网播放保护

打开「外网播放传输保护（忽略内网）」。在「外网播放时」选「暂停上传与复制」可暂停上传和文件夹复制/移动队列；全部外网播放停止或暂停后，按设置延迟恢复本插件暂停的任务。某些递归合并和网盘服务端秒传没有可暂停的父任务接口，插件只能控制其中进入上传/复制队列的任务。

选「限制上传速度」再填写上限（KB/s，例如 `200`），会使用 CloudDrive2 全局上传限速，结束后恢复原值。令牌还需「获取系统设置」和「修改系统设置」（`allow_get_system_settings`、`allow_modify_system_settings`）；无法设置时回退到暂停。原本已经更低的限速会继续保留。

反向代理或 VPN 把外网会话上报为私有 IP 时，可在「视为外网的代理来源 IP/CIDR」中填专供外网接入的来源，例如 `192.168.50.18/32`。如果内外网共用同一个代理出口，先让 Emby/Jellyfin 能识别真实客户端 IP，否则该地址上的内网播放也会触发。保留默认的内网忽略规则时，留空此项。日志会记录识别到外网播放、没有外网播放或状态无法确认。
