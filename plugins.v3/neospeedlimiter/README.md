# NEO播放限速

外网播放时，按播放码率为下载器分配剩余上传带宽。

- **按比例**：按所填比例分配；留空时均分。
- **按下载器顺序**：先满足列表靠前的下载器，后面的先让出带宽。可用于同时运行 PT、公开 BT 下载器。
- **下载器上传上限**：每行填写 `下载器名称=KB/s`。TR 使用十进制 KB/s，qB 使用 KiB/s；未填写时保留启用前的上传上限。
- **智能限速上行带宽**：填写可稳定使用的上行带宽，单位 Mbps。
- **预留带宽、播放带宽系数**：给其它流量和播放突发留出余量。

开播、恢复或拖动后的15秒及码率缺失时优先让出上传。暂停或停止后等待所设时间，按所设步长逐步恢复；未配置下载限速时保留下载设置。停用时恢复插件修改前的设置，不覆盖期间手动修改的上传值。

可选“按播放片段预留”：Emby 直接播放时，后台读取本地文件附近的数据包，按未来一分钟内的30秒窗口估算需求，并留15%余量。媒体服务器与MP的路径不同时，每行填写 `媒体服务器路径=MP路径`。单次探测超时20秒，输出上限16MiB，只同时探测一个片段；不可读、未完成或转码时使用媒体服务器码率和播放带宽系数。

切换探测区间时复用仍有效的数据，避免扫描期间反复退回保守限速。文件属性在后台读取，停用时结束探测进程。日志记录片段估算、回退原因和播放预留带宽。

分段预测不测量客户端缓存或实际网络吞吐。经代理访问时，应核实不限速地址范围，避免远程播放被识别成内网播放。

## qBittorrent 批量下载

在「NEO播放限速」中选择 qBittorrent，打开「无播放且 qB 下载任务达到 3 个时解除上传限速」并保存。此开关默认关闭。每台 qBittorrent 独立统计下载中、排队和等待资源等未完成下载任务。达到 3 个后解除全局上传限速，剩余任务降到 1–2 个时继续不限速。参与统计的任务清空后恢复未播放上传限速。留空时恢复解除前的值。

内网或外网开始播放视频后恢复上传限速。外网播放使用原有的播放限速策略。播放结束并经过插件的恢复等待时间后，如果当前批次还有任务，继续放开上传。播放器或任务状态查询失败时恢复上传限速，查询正常后再判断。常规和备用上传限速分别保存和恢复。升级后，插件会恢复旧版临时解除的下载限速。

## 安装

在 MoviePilot V3 添加市场仓库 `https://github.com/felix-klk/MoviePilot-Plugins`，搜索并安装「NEO播放限速」。插件 ID 为 `NeoSpeedLimiter`，安装后重新选择下载器和填写速率。旧「播放限速」应先停用，让其恢复托管的限速，再由新插件接管同一台下载器。

基于 Shurelol 的 [播放限速 2.3.3](https://github.com/jxxghp/MoviePilot-Plugins/tree/main/plugins.v2/speedlimiter)，按 GPL-3.0 发布。
