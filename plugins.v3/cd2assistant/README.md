���в��ԣ�`python -m unittest discover -s tests -v`��## 从插件商城安装

1. 在 MoviePilot V3 的第三方插件仓库中添加：

   `https://github.com/felix-klk/MoviePilot-Plugins`

2. 刷新插件商城，搜索 **CloudDrive2助手**，选择来自本仓库的 **3.0.2** 版本安装或更新。
3. 打开配置，保留或填写 CloudDrive2 连接信息，开启“启用插件”和“外网播放时暂停上传（忽略内网）”。
4. 默认每 10 秒检查，所有外网播放停止或暂停后等待 45 秒恢复。

本插件与原 CloudDrive2助手使用相同插件 ID，以保留配置。若同时添加其他提供同名插件的仓库，请确认安装/更新来源为本仓库；从其他源更新可能覆盖此功能。CloudDriveDisk 无需替换。

插件依赖沿用原 CloudDrive2助手，MP 安装时需能下载 requirements.txt 中声明的依赖。未连接真实服务器联调，安装后请执行下方验证步骤。
